# Recovery checklist

1. Install Ubuntu 26.04 and complete the first login.
2. Install or restore the SSH key used for GitHub.
3. Confirm `ssh -T git@github.com`.
4. Clone this private repository and run `./install.sh`.
5. Log out and back in.
6. Open Kitty and verify Ctrl+Space, Shift+Enter, Yazi, Lazygit, and btop.
7. Restore personal files and security tooling from the separate data backup.

The desktop repository does not contain authentication material. Keep the
GitHub recovery method and Bitwarden recovery details somewhere independent of
the laptop.
